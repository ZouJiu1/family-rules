# 《家规试卷》目录索引

> 依据《生活规范以及指导家规》（full version 完整版.md）编写，作者一己之见仅供参考。
> 共29个年龄段（2岁～30岁），每个年龄3份试卷（简单/中等/难题），合计 **87份试卷**。
> 题型参考语文、数学、英语、历史等考试：选择题、填空题、判断题、连线题、排序题、计算题、材料分析题、英语翻译题、简答题、论述题、案例分析题、研究设计题。
> 敏感词一律用拼音驼峰代替（如 miYao、huangDuDu、seQing、duBo、ziWei、yiJing）。
> 每份试卷末尾均附【参考答案与解析】，解析注明原书章节出处。

## 各年龄段考查重点

- **2-5岁（幼儿）**：烫食放凉再吃、不挑食、早睡早起、刷牙、不吃陌生人食物、过马路牵手看车、勤洗手。
- **6-9岁（小学低年级）**：牛排全熟、玉米嚼碎、发烧不捂汗、口腔溃疡吃蔬菜、内裤袜子分开洗、晒太阳消毒、坐高铁先上厕所、少喝饮料、过马路细则。
- **10-13岁（小学高年级-初一）**：决策与计划、睡眠与记忆、酒精不碰、次氯酸/高温/紫外线消毒、资源有限（猪腿份额）、不占便宜、针孔摄像头防范、低价美食与亚硝酸盐案例、miYao防范、huangDuDu远离。
- **14-17岁（初中-高中）**：成瘾机制（监督学习被破坏）、第9章两性常识（拼音处理）、战争与资源、包子铺招牌、游泳安全、失眠入睡、换位思考、职业启蒙、雷劫与独立思考。
- **18-21岁（高中-大学）**：第9章全章、零工市场纪实、酒吧miYao防范、节假日孝敬父母、献血车与低价美食警示、穷游错误、职业有用论、黄金与劳动价值。
- **22-26岁（考研-博士）**：监督学习与成瘾、资源有限与市场矛盾、寿命与贡献、温度与文明猜想、批判性分析原书个人猜想、研究设计、实践出真知。
- **27-30岁（工作人士-家长）**：职场规则（吃饱饭干活、不主动辞职、计件计时）、工厂有毒工序防护、空调电费与暖床省钱、同事交往、全书综合与下一代教育实践。

## 使用建议

1. 孩子每长一岁，按顺序做该年龄的"简单→中等→难题"3份试卷，难度递增。
2. 幼儿试卷（2-5岁）由家长读题，孩子口答或指认，不计时。
3. 做错的题目，回到原书对应章节复习（解析中已注明章节号）。
4. 29-30岁（家长）试卷含"教育实践题"，指导家长如何把本书内容讲给各年龄段孩子听。

## 维护说明（原书更新时）

1. 原书 `full version 完整版.md` 新增或修改内容后，只需同步修改受影响的试卷，不必全部重写。
2. 更新步骤：先确定变更章节 → 按上文"各年龄段考查重点"找到考查该章节的年龄段 → 重出该年龄段相关试卷中涉及变更知识点的题目，并同步更新【参考答案与解析】。
3. 新题目须遵守既有规范：敏感词拼音驼峰、计算题数字与原书一致、解析注明章节号、同龄3卷题目互不重复、不使用emoji。
